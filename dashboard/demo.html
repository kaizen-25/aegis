Every tool call stops here first: ALLOW, BLOCK or REVIEW, before anything runs.
✓ ALLOW

A rule permits it and it fits the task. The tool runs.

! REVIEW

Aegis can't be sure. The tool waits for a human.

✕ BLOCK

A rule forbids it. The tool is never called.

Strictest verdict wins: BLOCK over REVIEW over ALLOW. No matching rule means REVIEW.
